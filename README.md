# باقات ضيافة أرمادا ريزيدنس — موقع ثنائي اللغة

موقع ثابت (HTML وCSS وJavaScript) يعمل على GitHub Pages دون خادم أو قاعدة بيانات أو خطوات بناء.

## محتويات المشروع

```
index.html                      الصفحة الرئيسية
files/
  armada-coffee-break-buffet-ar.pdf   الملف العربي الأصلي المعتمد
  armada-coffee-break-buffet-en.pdf   النسخة الإنجليزية
assets/
  js/packages-data.js           ← كل المحتوى: الباقات والأصناف والأسعار والنصوص (عربي/إنجليزي)
  js/app.js                     منطق العرض وتبديل اللغة (لا يحتاج تعديلًا)
  css/site.css                  التصميم
  img/                          الشعار والصور ورمز QR لبوابة الشراكات
  fonts/                        خطوط النسخة الإنجليزية من الـPDF (رخصة OFL)
tools/
  print-en.html                 مصدر ملف الـPDF الإنجليزي
.nojekyll                       ملف مخفي يطلب من GitHub نشر الملفات كما هي
```

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub (عامًا Public)، مثلًا `armada-hospitality`.
2. من صفحة المستودع: **Add file ← Upload files**، ثم اسحب **محتويات** المجلد (لا المجلد نفسه)، بحيث يكون `index.html` في المستوى الأول. ثم **Commit changes**.
3. **Settings ← Pages**، وفي **Build and deployment** اختر: Source = **Deploy from a branch**، والفرع **main** والمجلد **/(root)**، ثم **Save**.
4. بعد دقيقة أو دقيقتين يظهر الرابط بالشكل: `https://اسم-الحساب.github.io/armada-hospitality/`

جميع المسارات نسبية، فيعمل الموقع داخل مسار المستودع دون أي تعديل.

**ملاحظات:**
- ملف `.nojekyll` مخفي، وقد لا تُرفعه بعض الأنظمة بالسحب والإفلات. الموقع يعمل بدونه، فلا داعي للقلق إن لم يُرفع.
- الموقع يفتح بالعربية افتراضيًا ويتذكّر آخر لغة اختارها الزائر.
- لفتح النسخة الإنجليزية مباشرة (مثلًا لرمز QR منفصل) أضف إلى الرابط: `?lang=en`

## تحديث الباقات أو الأسعار

كل المحتوى في ملف واحد: `assets/js/packages-data.js`.

- **تعديل سعر:** غيّر الرقم في السطر `price: 35,` للباقة المطلوبة.
- **تعديل صنف:** كل صنف مكتوب هكذا: `i("الاسم بالعربية", "English name")`. عدّل النصين معًا للحفاظ على التطابق.
- **إضافة صنف:** انسخ سطر صنف موجود وعدّله. لا تنسَ الفاصلة بين الأصناف.
- **عدد الأصناف** و«من 15 ريالًا» و«12 باقة» تُحسب تلقائيًا، فلا تحتاج تعديلًا.

بعد الحفظ ارفع الملف المعدّل إلى المستودع بالاسم نفسه. وتذكّر أن تعديل الموقع لا يعدّل ملفَي الـPDF، فحدّثهما أيضًا (القسم التالي).

## تحديث ملفَي الـPDF

يجب الإبقاء على **الاسمين نفسيهما** حتى تبقى أزرار التنزيل تعمل:

- **العربي:** استبدل `files/armada-coffee-break-buffet-ar.pdf` بالملف المعتمد الجديد بالاسم نفسه.
- **الإنجليزي:** يُولَّد من بيانات الموقع نفسها:
  1. افتح `tools/print-en.html` في متصفح **Google Chrome**. يمكن فتحه من جهازك مباشرة بعد فك الضغط.
  2. اضغط **Ctrl+P** (أو **Cmd+P** في الماك).
  3. اختر: الوجهة **Save as PDF**، الهوامش **None**، وفعّل **Background graphics**.
  4. احفظ الملف باسم `armada-coffee-break-buffet-en.pdf` داخل مجلد `files`.

  إذا زادت الأصناف كثيرًا، تصغّر الصفحة خط القائمة تلقائيًا بنسبة بسيطة لتبقى في صفحتها. راجع الصفحات بالنظر قبل الرفع.

قد يعرض المتصفح النسخة القديمة لبضع دقائق بسبب التخزين المؤقت. يكفي التحديث القسري (**Ctrl+Shift+R**).

## الخطوط

- **الموقع:** IBM Plex Sans Arabic للعربية وManrope للإنجليزية، تُحمَّل من Google Fonts. إن تعذّر تحميلها يستخدم الموقع خطًا احتياطيًا.
- **الـPDF الإنجليزي:** Instrument Sans وCrimson Pro المضمّنان في `assets/fonts`، لأن Manrope لم يكن متاحًا عند إعداد الملف.

## تجربة الموقع محليًا

افتح `index.html` مباشرة في المتصفح.

ملاحظة: بعض المتصفحات لا تنفّذ خاصية `download` للملفات المحلية، فتفتح الـPDF بدل تنزيله. هذا لا يحدث بعد النشر على GitHub Pages.
